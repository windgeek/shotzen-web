# ShotZen support website (moved)

ShotZen’s support and privacy pages now live on Song Li’s site:

- Support: https://songli.me/apps/shotzen/support/
- Privacy: https://songli.me/apps/shotzen/privacy/

Each language has its own page there (`…/support/zh-Hans/`, `…/privacy/ja/`, and so on).
Their source is in the private `windgeek/songli.me` repository
(`src/pages/apps/shotzen/`, content in `src/data/shotzen/`).

This repository keeps the old addresses working. `index.html` and `privacy.html`
are static redirects, generated by `python3 scripts/generate.py`, to the matching
page on songli.me. They pick the language the old pages would have shown:
`?lang=`, then the choice saved in the browser, then the browser languages, then
English (also the fallback without JavaScript). GitHub Pages publishes the root
of `main`. Issues for ShotZen are still welcome here.
